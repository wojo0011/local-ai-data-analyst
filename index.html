03 · Mathematics & statistics

Show the math behind the claim

Statistics compresses a dataset into evidence. Each metric below includes the equation, interpretation, and the assumptions you should challenge.

Load data to calculate univariate statistics. Comparison is optional.

Mean
\(\bar{x}=\frac{1}{n}\sum_{i=1}^{n}x_i\)
—

The arithmetic centre. Sensitive to extreme values.

Sample standard deviation
\(s=\sqrt{\frac{\sum (x_i-\bar{x})^2}{n-1}}\)
—

Typical spread around the sample mean, using Bessel's correction.

Median
\(\tilde{x}=Q_{0.5}\)
—

A robust centre: half the observations lie above and half below.

IQR outlier rule
\([Q_1-1.5IQR,\;Q_3+1.5IQR]\)
—

A diagnostic flag, not proof that an observation is wrong.

Pearson correlation
\(r=\frac{\operatorname{cov}(X,Y)}{s_Xs_Y}\)
—

Linear association from -1 to +1. Correlation is not causation.

OLS regression
\(\hat{y}=\beta_0+\beta_1x\)
—

Fits the line minimizing squared residuals; R² reports explained sample variance.

06 · How the system works

What each layer is responsible for

The architecture deliberately separates computation, statistical reasoning, language understanding and presentation.

CSV

Raw observations

A CSV is a rectangular dataset: rows are observations; columns are variables. Before analysis, we must infer types, count missing values and understand units.

DuckDB-Wasm

Deterministic compute

DuckDB runs SQL in WebAssembly. Filtering, grouping, descriptive statistics and reproducible queries happen here—not inside the language model.

Statistics

Evidence & uncertainty

Means, quantiles, dispersion, correlation and regression summarize patterns. They describe the observed sample; causal claims require stronger design and assumptions.

Transformers.js

Semantic navigation

Embeddings map text into a vector space so conceptually related questions and schema descriptions can be compared numerically.

WebLLM

Natural-language reasoning

The local LLM translates evidence into explanations and next-step questions. It is useful for interpretation, but deterministic SQL remains the source of numeric truth.

D3 + ECharts

Visual explanation

D3 draws the architecture graph; ECharts renders interactive analytical views. Visualization is a diagnostic tool, not decoration.

Engineering decisions
Progressive enhancement

CSV + SQL + statistics work without WebGPU. AI features are opt-in because model downloads and GPU requirements are materially heavier.

Privacy by architecture

The app has no analysis backend. Data context is assembled locally and supplied only to a model executing in the same browser session.

Guardrails against hallucination

The LLM receives bounded evidence and is told to label unsupported ideas as hypotheses. Numbers should be reproduced with SQL.

GitHub Pages compatible

Everything is static HTML, CSS and JavaScript. Heavy runtimes are loaded from public package/model hosts at runtime.
